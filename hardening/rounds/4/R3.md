```
id: R3-4-01
severity: blocker
location: workspace/kit/gates/red_check.py:55-62,71-72 (worktree of base, run_tests exit code)
evidence: PHP repo, vendor/ untracked. test_cmd "tests/run.sh" -> exit_base 127 ("vendor/bin/phpunit: not found"), exit_head 0, pass true
problem: Any non-zero exit on base counts as red, and a fresh git worktree has no vendor/, node_modules, obj or target, so on PHP, .NET restore-less and Node repos the base run always fails to start and every change "proves red".
proposed_fix: Drop the worktree: in the CI checkout (disposable) restore the changed production files from base with `git show`, run the tests where the dependencies already are, then `git checkout HEAD --` them back; and treat exit 126, 127 and timeout as an error finding, not red.
```
