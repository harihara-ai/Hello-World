id: R3-2-01
severity: major
location: workspace/kit/gates/trace_check.py:17 (TEST_ID lookbehind)
evidence: `echo '{"spec_dirs":[...]}' | trace_check.py -` with tests/FeeTest.php `testREQ_FEE_001_late`, src/test/java `shouldReq_Fee_002`, UnitTests/uFeeTests.pas `TestReq_Fee_003` -> "REQ-FEE-001/002/003 has no test"; only bare `Req_Fee_004` matched
problem: `(?<![A-Za-z0-9])` rejects a letter before REQ, but PHPUnit (`test` prefix), DUnit/DUnitX (`Test` prefix) and JUnit (`should`) names glue the ID to a prefix, so the F02 fix still fails on the common convention.
proposed_fix: Use `(?<![0-9])REQ[-_]...` (digit-only lookbehind); a false hit like `PREREQ_X_1` is a harmless orphan warning.
confidence: high

id: R3-2-02
severity: major
location: workspace/kit/scripts/cov_import.py:84-90 (match), :56-58 (Cobertura branch)
evidence: coverlet-style file, `<sources>` Billing.Api and Billing.Core, both with `filename="Program.cs"`. parse_report keys {'Program.cs': {5}} (Core line 5 hits=0 merged with Api line 5 hits=1 -> "covered"). match('src/Billing.Core/Model/Fee.cs') -> 'Fee.cs'
problem: Relative Cobertura filenames are never resolved against `<sources>`, so same-named files in different projects (Program.cs, Startup.cs, Index.php) merge and a suffix match also accepts `Model/Fee.cs` for `Fee.cs`, giving a false pass on changed-line coverage.
proposed_fix: In the Cobertura branch, prefix each relative filename with every `<source>` that exists on disk (fall back to repo-relative), keep the full path as key, and match on whole path segments only.
confidence: high

id: R3-2-03
severity: major
location: workspace/kit/gates/coverage.py:42-50; core/policy.yml done_gates; scripts/policy.py (list may only grow)
evidence: Delphi fixture, inputs/coverage.json `{"baseline_total":0}` -> coverage missing_input, done can never pass. Hand-written `{"changed_lines":{"src/uFee.pas":[3]},"covered_lines":{"src/uFee.pas":[3]},"baseline_total":50,"current_total":90}` -> pass true, only a warn manual_evidence

id: R3-2-05
severity: major
location: workspace/kit/scripts/kitconst.py:10-13 (TEST_GLOBS, matches)
evidence: is_test_file: `Tests/Helpers/uMock.pas` False, `Test/uMock.pas` False, `tests/a.php` True, `MyApp.Tests/Helpers/Builder.cs` True
